
# Hostel Room Allocation and Student Accommodation Analysis System

## Project Description
This project is developed to manage hostel students, rooms, room allocation and fee details. It also provides data analysis and visualizations.

## Technologies Used
- Java
- Python
- MySQL
- JDBC
- Pandas
- Matplotlib
- Visual Studio Code

## Main Features
1. Student Management
2. Room Management
3. Room Allocation
4. Room Checkout
5. Fee Management
6. Student Data Analysis
7. Room Occupancy Analysis
8. Fee Payment Analysis
9. Data Visualization

## Database Tables
- Student
- Room
- Room_Allocation
- Fee

## Project Structure
- Java Files – Application implementation
- hostel_analysis.py – Python data analysis
- lib – MySQL JDBC Connector
- SRS_Document.txt – Requirements document
- Use_Case_Diagram.md – Use Case Diagram
- Class_Diagram.md – Class Diagram
- System_Architecture.md – Architecture Diagram
- ER_Diagram.md – ER Diagram
- Database_Design.sql – Database design
- SQL_Queries.sql – SQL queries
- Normalization.md – Database normalization
- Testing_Documentation.md – Testing details

## Conclusion
The system simplifies hostel room allocation and fee management. It also helps analyze room occupancy and student accommodation details.
